# HelloTalk Interaction Model

How different interaction types work and how they drive engagement.

## Interaction Types

### 1. Direct Messages
- Primary interaction method
- First message to a new user = "partner request"
- Free users: limited number of new conversations per day (exact limit TBD)
- VIP: unlimited new conversations
- Messages support: text, voice, image, video, stickers

### 2. Moments
- Public posts visible to the community
- Can be text-only or text + images
- Other users can: like, comment, correct, translate
- Moments corrections are a key engagement driver — correcting someone's post often leads to a conversation

### 3. Corrections
- Inline grammar/spelling corrections on messages or moments
- Correction UI lets you mark specific text and provide the fix
- Receiving corrections is a core value prop — users appreciate them
- Giving corrections = goodwill + visibility + often starts a chat

### 4. HelloTalk Live
- Audio rooms with hosts and listeners
- Joining/hosting rooms increases profile visibility
- Good for exposure to many users at once

### 5. Likes and Comments
- Lower-effort interactions on moments
- Likes are passive; comments can start conversations
- Frequent liking/commenting may increase your visibility in someone's feed

## Engagement Funnel

```
Discovery/Search → View Profile → Send Message → Conversation → Language Exchange
         ↑                                              |
         |                                              v
    Moments ←── Corrections ←── See their post in feed
```

## Strategies for More Interactions

### Inbound (get people to message you)
- Complete profile with good photos and voice intro
- Post moments in your target language (invites corrections)
- Be active during peak hours for your target language
- Use HelloTalk Live rooms

### Outbound (start more conversations)
- Correct people's moments (high conversion to chat)
- Comment thoughtfully on moments
- Send personalized first messages referencing their profile/posts
- Use discovery filters strategically
