# Tandem — Blocked Ideas

Ideas we considered and rejected, so we don't revisit them.

---

## API reverse engineering of Tandem's backend
**Why blocked (for now)**: We already diagnosed the likely root cause from profile screenshots alone (bio keyword suppression). Reverse engineering Tandem's API would take multiple sessions of work and its main value would be to confirm a diagnosis we can already test with a 2-minute bio fix. Deferred unless Phase 2 (bio fix observation) fails to show recovery, at which point reverse engineering might be the only way to get direct diagnostic access to the account's suppression state.

## Multiple accounts / new Tandem account
**Why blocked**: Same reasoning as HelloTalk. Tandem's terms prohibit multiple accounts and they can detect same-device registrations. Risk of device-level ban. The existing account has 6 positive references and an established language level — throwing that away to start fresh loses real value.

## Tandem Pro subscription as a fix
**Why blocked (tentatively)**: Tandem Pro provides some visibility features, but the user's issue is not "ranking too low" — it's "being actively suppressed by a moderation flag." Paying for Pro does NOT override a moderation suppression on any platform I'm aware of. Would be paying for features we can't use. If the bio fix clears the suppression and the user later wants to optimize ranking further, Pro becomes a reasonable consideration then.

## Automated messaging / outreach to new users
**Why blocked**: Same reasoning as HelloTalk safety rules. Tandem's bot detection is strict. Automated DMs or batch outreach would trigger detection and make the situation worse, not better.

## Posting "political" or "controversial" content to build engagement
**Why blocked**: The original problem is that a politically-flavored word ("conspiracy theories") appeared in the bio. The absolute last thing we should do is double down on politically-sensitive content. Stay on safe topics (language, culture, travel, food, hobbies). Save all opinions for private DMs with trusted partners, not public-facing profile content.

## Posting the bio change as "evidence" in any support ticket or external complaint
**Why blocked**: Admitting to editing the bio reads as admitting fault, which gives any support team a cheap off-ramp. The facts are (a) the original content was acceptable when posted in 2024 and (b) the platform changed the rules retroactively. That framing is much stronger than "I fixed my bio." If a future support ticket is needed, frame it as "my clean account is wrongly suppressed, please fix it" and let Tandem's trust team find the bio edit in their own logs if they want to.
